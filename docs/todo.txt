- DECIDED (2026-08-25): the short-participle row is shown only when its form
  differs from the ter/haver row above it.  option (b) of the three below.

  why: measured against the dev db, 1 verb of 15 has a distinct short form
  (aceitar, aceitado/aceite).  for the other 14 the row was the answer above it
  typed again -- 100% correct over 8 attempts vs 93% for the row it copies --
  and 10 of them drilled blank for want of an example sentence.  it also
  narrows the unverified ter/haver vs ser/estar claim (see VERIFY above) to
  exactly the verbs where it is the documented rule.

  cost: the EXISTENCE of a second form is leaked before the learner answers,
  though not its content.  accepted: a row that only appears when it teaches
  something is worth more than a row that never does.

  implemented as a display rule -- LanguageAdapter.contrastive_rows names the
  (tense, person, mirrors) triple, api._contrast drops the row when the forms
  match.  both rows are still stored and seeded, so reverting to (a) is
  returning [] from the adapter.  no migration, no data lost.

  hiding the row also drops the surviving row's "ter / haver" label.  that
  label is only true as a contrast with a visible "ser / estar" beneath it:
  partido is what you use with either auxiliary, so a lone labelled row would
  assert a restriction the verb does not have.  unlabelled it falls back to the
  tense heading, as the gerund already does.

  it also needed no example backfill: aceitar is the only verb that still shows
  the row and its sentence was already correct.  the two wrong ter-auxiliary
  sentences the survey found (ouvir, por) are now on hidden rows.

  the options that were considered:
    (a) always show both rows.  no leak, but asserts a distinction that is
        vacuous for 14 verbs and needs ~12 sentences for rows that teach
        nothing.
    (c) collapse to ONE row accepting either form, revealing the other after
        answering (the FormVariant mechanism, as for oico/ouco).  no leak at
        all, but gives up drilling which auxiliary takes which.

  still open, and may yet argue for (c): for ser/ir/ter/poder there may be no
  natural ser/estar sentence at all ("foi sido" is not Portuguese).  under (b)
  this is no longer urgent -- those rows are hidden anyway -- but if the row
  cannot take a natural sentence for a verb that DOES have a distinct short
  form, that is an argument the row should not exist.

- spanish follow-ups (added 2026-09-09, with the es release):
  - an option to hide the vosotros row.  drilled by default because US
    textbooks print the row and AP expects recognition, but a learner aimed
    only at latin america has no use for it.  latin american "ustedes" reuses
    the ellos row, so hiding vosotros leaves no gap -- it is a display rule
    like contrastive_rows, not a data one.
  - pt-BR.  the same shape of question, but a different source: cplp.org's
    paradigm tables are IDENTICAL under both editions (only the lemma
    inventory differs), so the edition cookie cannot deliver it.  and it is
    more than a person swap -- voce displacing tu with 3rd-person agreement,
    voces for vos, no falamos accent, different clitic placement.
  - DONE (2026-09-09): reflexives now substitute.  typing levantarse adds
    levantar, via LanguageAdapter.substitute; the confirmation says why.  the
    clitic is fixed per person and adds no conjugation -- of levantarse's 85
    cells, 78 are the plain form with a pronoun in front and 1 is identical.
    the reflexive SENSE still reaches the learner through the example
    sentences, which guidance.json now tells the model to mix with the plain
    sense.
  - italian has the same clitic question (lavarsi) and substitute() returns
    None there.  it/reverso drops particletxt entirely, so an italian
    reflexive would store bare forms today -- latent, since none is drilled.
  - stem-changers still classify as "irregular".  pensar->pienso is not
    recoverable from the infinitive (pensar changes, pasar does not).  it
    understates regularity rather than overstating it, but covers a lot of
    ordinary spanish 1 vocabulary.  needs the three stem-change classes as
    extra patterns.
  - no hand-checked es seed, so no equivalent of tools/voc_check.py.  same
    debt italian already owes.  tools/spanish_endings.py --check is the only
    canary for reverso changing shape under us.
